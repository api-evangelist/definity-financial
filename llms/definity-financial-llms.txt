# Definity Financial

> Definity Financial Corporation (TSX: DFY) is a Canadian property and casualty insurance
> group headquartered in Waterloo, Ontario — the demutualized successor to Economical Mutual
> Insurance Company (founded 1871). It underwrites personal, commercial, farm and pet lines
> across Canada through four brands: Economical (broker-distributed), Sonnet (direct-to-consumer
> digital), Family Insurance Solutions, and Petline/Petsecure. Definity publishes NO public,
> self-serve developer portal and NO downloadable OpenAPI, AsyncAPI, GraphQL or Protobuf
> definition. Its API surface is real but entirely partner-gated: broker/BMS connectivity runs
> through gated intermediary channels, and Definity is CSIO API Security Standards Certified
> (November 27, 2024) — the Canadian P&C industry's standard authentication and authorization
> API model for insurer-to-broker-management-system data exchange.

## Company

- [Definity Financial](https://www.definityfinancial.com/): Corporate site and investor material (TSX: DFY).
- [Economical Insurance](https://www.economical.com/): Broker-distributed home, auto, farm, business and surety lines.
- [Sonnet Insurance](https://www.sonnet.ca/): Direct-to-consumer fully digital carrier (auto, home, condo, tenant, landlord, pet).
- [Petsecure](https://www.petsecure.com/): Petline/Petsecure pet insurance brand.

## APIs

None published. There is no public, documented, self-serve API for Definity Financial or any
of its brands. `api.definity.com` resolves behind an Imperva edge and answers HTTP 404 with an
empty body to every anonymous path, including `/openapi.json`, `/swagger.json`, `/api-docs`,
`/graphql`, `/.well-known/openid-configuration` and `/.well-known/oauth-authorization-server`.
`broker.economical.com` is a Docebo SaaS learning management system serving broker training
courseware behind a login wall, not an API reference. See `review.yml` for the full probe log.

## Standards and certification

- [CSIO API Security Standards Certification — Definity](https://csio.com/news/csio-congratulates-definity-financial-corporation-achieving-api-security-standards): Awarded November 27, 2024. CSIO's standard authentication and authorization API model for insurer/BMS connectivity, built by the INNOTECH Advisory Committee's API Security Working Group; addresses OAuth 2.1 security concerns and API endpoint concerns.
- [CSIO Certified Members](https://csio.com/csio-certification/certified-members): Definity is listed as API Security Standards Certified, eDocs Certified and Compliance Certified (all Z-Codes eliminated from broker data exchange).
- [CSIO](https://csio.com/): Centre for Study of Insurance Operations — Canada's P&C data-standards body (the Canadian counterpart to ACORD). Maintains eDocs, EDI, XML, XML Dataset, JSON, API Security and Commercial Lines Data Standards, plus CSIOnet and My Proof of Insurance.
